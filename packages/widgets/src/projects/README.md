# Projects

Type key `projects`, export `Projects`. Port of the old Beacon `projects` card.

Project finder: search (each word must hit name, nick, emoji, tags, one-liner or description), sort select (Recently worked, Best match, Most sessions, Name A–Z), link to the full list, up to 12 rows with emoji tile and globe link.

States: loading, empty, error, ready. Stories: Ready, Loading, Empty, Error, Parity (old Sandbox sample at the old card size).
