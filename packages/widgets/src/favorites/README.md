# Favorites

Type key `favorites`, export `Favorites`. Port of the old Beacon `favorites` card.

Grouped copy-the-command rows (label, shell, monospace command, copy button that says copied for 1.5 s), each group's note or a collapsible notes block, optional live readouts on top.

States: loading, empty, error, ready. Stories: Ready, Loading, Empty, Error, Parity (old Sandbox sample at the old card size).
